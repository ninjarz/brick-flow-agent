## 架构与发布

- `workspaceSession.ts` 统一项目替换、几何修改、显式世界编辑、撤销/重做和试演事务；`useWorkspace` 为 React 提供稳定的快照订阅与最新状态读取。
- `useWorkspacePersistence` 集中恢复、保存调度、正式快照选择及保存状态；`storageCoordinator` 建立删除屏障。
- `requestLifetime` 集中取消与超时资源清理。
- `worldEntityCore`、`worldStateStorage`、`worldScenarioMigrations` 分离运行时实体操作、存档解析和内置剧本迁移；保留原导出入口供调用方兼容。
- CI 使用共享 `verify:quality`；部署前补生产浏览器检查。`verify:release` 在质量检查之外执行本机性能预算。
- 界面显示恢复/保存/存储失败状态；试演期间保存正式快照，避免重载把临时试演误当正式编辑。

## 性能测量

修改前本机对 10,000 个栅栏同步三次为 3309/3304/3295 ms。空间邻居索引替代每栅栏全量扫描后，早期验收测量约 30 ms；精确连接判断保持原规则，并增加桶边界和极大有限坐标回归。

模拟协议在模型不变时只发送 world：本机结构化复制 100 次的样本从约 166 ms（1500 方块+60 NPC）降到约 23 ms（60 NPC）。这是复制成本对比，不应解释为整个模拟或帧率按相同比例提升。

生产浏览器增加 1500 方块+60 NPC 的十秒测量，记录资源、长任务、帧间隔、前后堆大小及实际模拟推进。初次有效采样帧间隔中位数 16.7 ms、95 分位 17.6 ms，堆约 57→56 MB。最终测试会生成独立 JSON 附件；数值随机器负载变化，CI 不设绝对帧率阈值。

这次没有做真实模型服务的兼容性矩阵、跨设备 GPU 测试或数小时内存浸泡；短时性能样本不能证明不存在长期泄漏。生产包仍有几何/Three.js 相关大 chunk 警告，未通过单纯提高阈值隐藏。

## 最终验收结果

`npm run verify:release` 最终退出码为 0，全部通过：

- ESLint、TypeScript 与 Vite 生产构建。
- 87 个单元测试文件、408 个测试。
- 15 个开发版浏览器流程、2 个生产版浏览器流程。
- 默认模型校验、LDraw 覆盖审计、OBJ 连通性审计、本机性能预算。
- `git diff --check` 无空白错误。

最终 CPU 样本：10,000 栅栏同步 24.83 ms；100 次完整 world+plan 复制 163.08 ms，仅 world 复制 23.42 ms。

最终浏览器样本：10 秒采样记录 601 帧，帧间隔中位数 16.7 ms、95 分位 17.6 ms，堆约 50.5→40.7 MB，持久化模拟时间约 10.1 秒。资源计时按浏览器 Performance API 原始值保存在同目录 `browser-performance.json`，不将个别 Worker 资源计时异常解释为真实负延迟。

所有修改保留在当前工作区，尚未部署到线上。审查报告对应的是修改前基线，本文件对应本轮实现和验收。
